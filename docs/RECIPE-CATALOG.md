# Каталог рецептів і спільне меню

До Ours інтегровано пакет `Ours_recipes_55_import.zip`: 10 гарнірів, 18 м’ясних/рибних страв, 17 салатів і 10 повноцінних страв. Оригінальні дані збережені в `src/data/ours-recipes.json`, 55 незмінених JPEG — у `public/recipes/ours55`. HTML-перегляд з архіву не виконується і не включений у застосунок. Окремий `src/data/recipe-corrections.json` містить редакційну правку за проханням користувача: рецепт із початковим ID `meat_patties_gravy` показується як «Биточки» — відбиті курячі або свинячі шматочки без фаршу й підливи. Початковий запис та його зображення з ZIP залишаються незмінними для аудиту.

Каталог відкривається кнопкою книжки на вкладці «Меню». Пошук працює за назвою страви й продуктами; є категорії, обмеження часу, сортування та окремий показ власних рецептів. Картка містить зображення, час, складність, продукти, кроки та примітки. У каталозі **17 згенерованих ілюстрацій і 38 тимчасових обкладинок**, а не фотографії всіх готових страв. Ілюстрація до «Биточків» окремо згенерована для виправленого рецепта; початкове зображення з ZIP збережено. Інтерфейс чесно позначає ілюстрації та обкладинки. Початкові посилання для пошуку збережені в оригінальних даних і базі.

Усі рецепти пакета розраховані на **1 базову порцію**. Кнопки +/− змінюють кількість від 1 до 12. Маси, об’єми, яйця та часник перераховуються; «за смаком» залишається без вигаданої кількості. Нульова кількість авокадо в зеленому салаті збережена як альтернативний інгредієнт із початковою приміткою (60 г на порцію замість огірка) і не потрапляє у покупки автоматично. Час приготування не множиться. Власному рецепту можна задати іншу базову кількість порцій.

Меню — один довільний спільний список, без режимів «три частини» та «повноцінна страва». Достатньо додати лише салат. Генератор пропонує випадковий рецепт для перегляду; додавання лишається явною дією.

Додавання страви одночасно формує покупки. Однакові назви та одиниці підсумовуються між усіма активними стравами; різні одиниці не змішуються. Одиниці часнику нормалізовані. Зміна порцій або видалення страви оновлює пов’язані продукти, ручні покупки зберігаються. Продукт можна прибрати як наявний удома; кнопка повернення прихованих продуктів у меню скидає цей вибір. Кількість пов’язаного продукту змінюється через порції меню. Куплені товари залишаються в історії, завершене меню не створює їх повторно без явної команди «Знову сформувати покупки».

Рекомендації працюють в обох напрямках: м’ясо/риба → гарніри, гарнір → м’ясо/риба. Рейтинг поєднує початкові рекомендації пакета з правилами для кисло-солодких, медово-гірчичних, вершкових соусів, підливи, риби, хрусткої скоринки й запікання. Найвищий рейтинг показаний першим, разом із поясненням. Кнопка «Додати пару» атомарно додає обидві страви з вибраними порціями. Повторне додавання оновлює наявний запис, а не множить його. Це зрозумілі правила, без зовнішнього AI-сервісу.

Імпорт рецепта з URL читає Recipe JSON-LD, а за його відсутності — виразні розділи зі списком продуктів і кроками. TikTok імпортує лише публічний підпис відео та явно позначений у ньому список інгредієнтів; звукову доріжку не транскрибує. Якщо підпис не містить письмових кроків, рецепт можна зберегти з відеопосиланням і відкрити «Дивитися, як готувати». Нерозпізнані міри залишаються видимим початковим текстом без вигаданої кількості.

## База та повторний імпорт

У поточному Supabase міграції `005_recipe_catalog_shared_menu.sql` і `006_tiktok_video_recipes.sql` застосовані окремо. Міграція 006 дозволяє порожній список письмових кроків лише для перевіреного URL TikTok-відео; інші рецепти й далі потребують кроків. Повний `setup.sql` призначений виключно для нової порожньої бази.

- `recipe_catalog`: один глобальний набір із 55 записів, стабільні ID `ours55/<source-id>`, унікальна пара package/source_id. Оригінальний JSON зберігається в `original_data`. Авторизовані користувачі можуть тільки читати каталог.
- `meal_plan_items`: приватний простір пари, RLS, Realtime. Посилання на каталог або власний рецепт, порції й знімок продуктів. Унікальність за парою/рецептом.
- Запис меню та покупок виконується серверними RPC в одній транзакції з блокуванням простору. Клієнт не може передати підроблені продукти каталогу, змінити чуже меню або підробити прив’язку покупок.
- Власні рецепти й попередні особисті дані не копіюються, не видаляються і не стають публічними.

```sh
npm run import:recipes             # лише перевірка
npm run import:recipes -- --apply  # ідемпотентний імпорт пакета після міграції 005
```

Команда використовує токен лише зі змінної середовища, не виводить ключів і не записує їх у файли. Повторний імпорт перевірено: у базі залишаються рівно 55 унікальних записів.

## Інші зміни цього оновлення

Сюжет фільму тепер обмежений одним абзацом: до трьох речень і 650 символів, без номерів бібліографічних посилань. Обмеження застосовується в Edge Function, імпорті, формі та відображенні старих записів.

Кнопки збереження кіно, рецептів, бажань, подій, покупок і профілю перенесено на початок форм. Панель залишається видимою під заголовком під час прокручування. Додавання рецептів і підтвердження імпорту також розташовані зверху.

## Перевірки

- ESLint, TypeScript та production build для `/ours/`; manifest, шляхи й service worker перевірені окремо.
- 110 тестів: оригінальні дані та зображення, масштабування, симетричні рейтинги поєднань, PostgreSQL/RLS, атомарність, повторний імпорт, відсутність дублювання, виключення наявних продуктів, покупки й історія.
- 26 браузерних сценаріїв у WebKit/iPhone та Chromium; viewport 320×568, 390×664, 390×844, 844×390 і desktop. Основний документ не прокручується, каталог і деталі доступні в sheets, кнопки збереження залишаються зверху. Після останніх правок повторно перевірені відповідні сценарії, включно з каталогом у landscape.
- На тимчасових незалежних акаунтах у реальному Supabase перевірені каталог 55 записів, додавання пари, Realtime до партнера, зміна кількості в покупках, збереження після reload та відмова читання сторонньому акаунту. Тимчасові акаунти й простір прибрані.
- Production Edge Function повернула 200 для наданого UASerials-посилання з назвою «Початок» і сюжетом до 650 символів без перенесень рядка. Імпорт рецепта зберіг усі шість кроків контрольного джерела. Браузерний імпорт дозволений лише з налаштованого production-origin.
