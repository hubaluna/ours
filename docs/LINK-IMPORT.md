# Імпорт фільмів, бажань і рецептів

## Що працює

Розбір Open Graph, title/description та schema.org JSON-LD: Movie/TVSeries/VideoObject, Product, Recipe. YouTube/Vimeo мають окремий шлях через їхній публічний oEmbed. Назва, зображення, опис, відомий рік/жанр, ціна й інгредієнти показуються для перевірки перед збереженням.

Дані не вигадуються. У трейлера може бути назва й обкладинка, але не рік або жанр. Сайти з авторизацією, CAPTCHA, забороною автоматичного читання, великими відповідями або без метаданих можуть не підтримуватися. Для таких випадків є вставлення тексту / HTML та звичайні форми. Інгредієнти можна вибирати, редагувати, змінювати кількість і одиниці. Ціна іноземного магазину не підставляється як гривня.

У деморежимі **працює вставлення тексту / HTML**. Довільні URL не читаються через сторонній відкритий проксі: автоматичне читання потребує вашого Supabase й розгорнутої Edge Function. GitHub Pages сам по собі не може обійти CORS чужого сайту.

## Підключення з телефона

1. Для нового Supabase-проєкту один раз виконайте [setup.sql](../supabase/setup.sql). Якщо вже застосовували попередню версію ours., виконайте **лише [003_compact_movies_activity.sql](../supabase/migrations/003_compact_movies_activity.sql)**. Не запускайте повний setup поверх існуючої бази.
2. Supabase Dashboard → **Edge Functions → Deploy a new function → Via Editor**. Назва функції: **`link-preview`**.
3. Скопіюйте весь [link-preview-dashboard.ts](../supabase/link-preview-dashboard.ts) у `index.ts` редактора. Це згенерований один файл: вручну створювати допоміжні файли не потрібно.
4. Вимкніть перемикач старої gateway-перевірки **Verify JWT / Enforce JWT verification** для цієї функції. Це необхідно для сумісності з сучасними ключами підпису. **Сама функція обов’язково перевіряє користувача через Supabase Auth `getUser`, членство у просторі та ліміт запитів** перед будь-яким зовнішнім запитом.
5. Натисніть **Deploy**. Адміністративні ключі у frontend не додаються. `SUPABASE_URL` та `SUPABASE_ANON_KEY` надаються середовищем Supabase.
6. Підключіть Project URL і publishable key до ours. за [основною інструкцією](START-HERE.md), увійдіть і створіть простір для двох.
7. Відкрийте «Кіно», «Бажання» або «Покупки» → кнопку посилання. Вставте HTTPS-адресу, перевірте знайдені поля та збережіть.

За замовчуванням дозволений origin `https://hubaluna.github.io`. Для власного домену додайте у **Edge Function Secrets** змінну `ALLOWED_ORIGINS` зі списком точних origins через кому. Не додавайте `*`.

## Для Codex / CI

Модульна функція: `supabase/functions/link-preview/index.ts`, імпорти у `deno.json`. CLI-варіант: `supabase functions deploy link-preview --no-verify-jwt` з налаштованим обліковим записом Supabase. Для Dashboard файл генерується командою `npm run setup:edge`; після зміни модулів його слід перегенерувати.

Автоматичні перевірки запускають parser, HTTPS URL/DNS-фільтри, HTTP handler, редиректи, ліміти розміру, прив’язування TCP до перевіреного IP, відсутність пересилання cookies/Authorization, RLS і атомарний імпорт інгредієнтів. Deno перевіряє типи модульної та односторінкової функцій. 11 листопада 2026 року живий імпорт перевірено на Example Domain (бажання), YouTube (кіно) та Budget Bytes (рецепт). Функція також відхилила приватний URL та акаунт без простору.

## Захист

- Тільки авторизований учасник пари; 8 запитів за хвилину на користувача, ліміт перевіряє PostgreSQL.
- HTTPS, стандартний порт, без URL credentials; IP literal та локальні домени заборонені.
- Кожна DNS-відповідь і кожен redirect перевіряються; змішані public/private відповіді відхиляються. `Deno.connect` відкриває TCP лише до перевіреної IP-адреси; `Deno.startTls` перевіряє сертифікат і SNI вихідного hostname. Це обходить несумісність `node:https` з Edge Runtime без вимкнення TLS-перевірки. Ребайндинг не може перемкнути TCP на приватну адресу.
- Максимум 4 redirects, 20 секунд, 1,5 МБ HTML/JSON; несподіваний стиснений вміст відхиляється замість необмеженого розпакування.
- HTML не виконується та не вставляється в DOM застосунку. Повертаються лише обмежені текстові поля та HTTPS-посилання.
- Авторизація Supabase, cookies та інші користувацькі заголовки не передаються сайту-джерелу.
- Прев’ю та відповіді функції мають `Cache-Control: no-store`; service worker їх не кешує.
- Обкладинки з посилань можуть завантажуватися з сайту-джерела без referrer. Власні фотографії залишаються у приватному Storage.

## Кіно й повні рецепти

Імпорт фільму читає постер `img[itemprop=image]`, якщо сайт не має Open Graph. Для фільмів і серіалів виконується пошук Wikipedia; точний збіг назви заповнюється автоматично, інші результати потрібно обрати. Опис має посилання на джерело. Оригінальне відеопосилання зберігається окремо. TikTok читається через публічні метадані та oEmbed, з підтримкою коротких посилань. Назва з опису відео зіставляється з Wikipedia. Без доступного опису чи назви потрібне уточнення користувача; розпізнавання лише за кадрами/звуком не реалізоване.

Рецепт розділяється на `recipeIngredient` і `recipeInstructions` (включно з HowToSection/HowToStep). У Меню зберігаються фото готової страви, джерело, продукти та кроки приготування. Перед збереженням можна виправити поля; без фото, продуктів або кроків рецепт не збережеться. Стандартні одиниці нормалізуються, нерозпізнані міри залишаються в тексті. Категорія продуктів визначається за назвою; кількість та одиниці приховані в «Додатково».
