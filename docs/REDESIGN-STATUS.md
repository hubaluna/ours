# ours. 2 — реалізовані зміни

- Шість вкладок: Головна, Покупки, Меню, Кіно, Бажання, Календар.
- Покупки мають однорядковий вигляд: чекбокс, назва, кількість; висота 48 px замість 68 px. Автор, ціна й категорія доступні в деталях натисканням на назву.
- Спільний фон — нерухомий пастельний градієнт із блакитними, лавандовими, м’ятними й персиковими переходами. У темній темі застосовуються окремі приглушені відтінки.
- Основний екран має висоту viewport; списки посторінкові, деталі й форми розгортаються окремо. Збільшені панелі можуть прокручуватися. На низькому екрані місяць календаря відкривається окремо.
- Головна показує тільки непрочитані спільні зміни партнера; позначки перегляду персональні й зберігаються. Власні зміни та бронювання подарунків не потрапляють у стрічку.
- Меню: спільний список довільних страв без поділу на режими. Каталог 56 рецептів із пошуком, фільтрами, порціями, двосторонніми рекомендаціями та автоматичними покупками. Можна додати лише салат. Власні й імпортовані рецепти збережені. [Подробиці та походження зображень](RECIPE-CATALOG.md).
- Кіно: спільний список, рік, жанри, опис, постер, джерело, статус перегляду, редагування.
- Імпорт: редагований preview фільмів/бажань і вибір інгредієнтів рецептів. Supabase та Edge Function підключені; читання зовнішніх URL перевірено для всіх трьох типів. Вставлення тексту залишається резервним шляхом.
- Шрифт e-Ukraine взято з офіційного сайту Мінцифри та розміщено локально; джерело в `public/fonts/NOTICE.md`.
- Старі SVG-ілюстрації прибрано. Новий оригінальний графічний актив створено спеціально для ours.; він використовується як невеликий акцент і заповнювач відсутніх фотографій. Іконки — Lucide.
- Скляна навігація й sheets мають blur, м’який контур, підсвітку та непрозорі fallback. Підтримуються темна тема, reduced motion/transparency, safe area і Visual Viewport.
- У поточному проєкті застосовані міграції 001–003 після адміністративної перевірки порожньої схеми. Повторний setup заборонений. База/RLS, незалежні сесії, запрошення, приватні фото, секретні подарунки та Realtime перевірені на тимчасових акаунтах. Обмеження перевірки email і Auth: [SETUP-VERIFICATION.md](SETUP-VERIFICATION.md).

- Кіно: автоматичне доповнення з Wikipedia, імпорт коротких TikTok-посилань за назвою в описі, постери UASerials, обов’язковий вибір оцінки 1–10 під час позначення перегляду.
- Покупки: категорія за назвою та історією; кількість, одиниці, ручна категорія й ціна приховані в «Додатково».
- Календар без подій сьогодні показує найближчі події й дні до них.
- Фон отримав пастельний рожево-фіолетовий шар. Переходи скорочені, вкладки попередньо завантажуються без блокування інтерфейсу.
- Для цього оновлення застосовано лише міграцію 004 після перевірки її відсутності. [Перевірки й межі](CINEMA-MENU-UPDATE.md).

- Застосована тільки відсутня міграція 005; каталог імпортовано зі стабільними ID без дублювання. Форми мають верхні закріплені кнопки збереження; сюжет фільму — один короткий абзац.
